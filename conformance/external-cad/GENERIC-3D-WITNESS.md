# Independent, data-driven 3D material witness

This is an additive **non-OCCT** physical acceptance mode, not a replacement for the
already admitted fixed KERNEL v5/v6 16-STEP/992-ray gate. It makes the next
source-authored selected-profile, curved-surface, positioned pocket or
browser-generated *single solid* testable without editing and recompiling the
probe for every new ray location.

## Explicitly independent input

`anvil_step_probe.rs --witness-3d ORIGINAL.step WITNESS.txt` imports the real
STEP through the pinned AnvilCAD Rust library, requires one exact warning-free
B-rep, checks watertight directed triangles and imported mesh volume/surface,
then casts full 3D rays along arbitrary world-space directions. Each witness
point declares **material** or **void**; occupancy comes from triangle-ray
intersection parity, not text entities, producer-reported properties, or an
OCCT same-engine readback. The witness specification is an independently
reviewed, versioned source document with bounded mass/area intervals; it is
never generated by reading the STEP file or its producer receipt.

The fixture `witness-v6-direct-two-cuts-8mm.txt` is intentionally small but
meaningful: orthogonal X/Y/Z rays, positioned diagonal slope, 8 mm stock,
circular blind pocket at (15,50) with 5 mm floor, a 14x8 mm through-window at
(95,10), corresponding outside material, and independently calculated
volume/area. This is a **general-purpose API demonstration using original
accepted native geometry**, not another unqualified U-bracket micro-predicate.

The 0-cut original is the **physical negative**: applying the two-cut witness
must fail specifically because its imported solid has the wrong material
volume/area or occupancy, *not* from an unreadable file, engine failure or
generic `NOT_QUALIFIED` diagnostic.

The runner verifies physical original STEP bytes against their actual native
six-stage source/binary receipt, a full immutable KERNEL checkout and worker
binary, independent compiled AnvilCAD probe, pinned upstream source and witness
byte hash. Source-to-binary compile log must be reviewed separately; hashes
alone cannot establish compilation provenance. The output includes a
fail-closed `qualification.json` and two raw external-process transcripts.
The runner cannot give a PASS until both original STEP files have genuinely
been independently imported and the physical negative rejected for geometry.

**Not yet qualified at implementation:** New Rust mode must be successfully
compiled and the above run actually executed. The prior 16-STEP admission remains
valid independently. This capability does not certify arbitrary curved
B-rep fidelity, multiple solids/assembly exports, browser-authored state,
Windows native binaries, or human CAD usability. Integration owns hosted
workflow wiring, evidence retention and guarded merge. No other owner lane
should be modified by this STEP worker.

## V2 — analytic full 3D mass distribution (candidate)

V1 and its exact independent importer receipts remain backward compatible.
The optional `INTUIT3D_3D_WITNESS_V2` specification requires `CENTROID`
(x, y, z, lower/upper pairs in mm) and `COVARIANCE` (xx, yy, zz,
xy, xz, yz lower/upper pairs in mm²), in addition to all V1 volume,
surface-area and world-coordinate material/void rays. Missing, duplicated,
nonfinite or excessively wide moments fail closed. The independent AnvilCAD
consumer integrates signed oriented triangles into tetrahedral first and
second volume moments, normalizes by their signed volume, and reports
`WITNESS_MOMENTS`. The Python custody runner refuses an absent/malformed
V2 mass receipt and retains nine measured values in `qualification.json`.
The V1 path does not claim these new moment predicates.

For the existing direct two-cut 8 mm sloped native STEP, the V2 oracle
`witness-v6-direct-two-cuts-8mm-moments.txt` was calculated **analytically**
from the six-edge source contour
`(0,0),(120,0),(120,20),(65,20),(45,80),(0,80)`,
minus a 14×8 mm through-window at (95,10) and a radius-5 mm,
3 mm deep blind cylinder at (15,50). The independently calculated
volume is **44468.380550981 mm³**, centroid
**(40.418510546, 32.455848620, 3.986753540) mm** and six
covariance components, in xx/yy/zz/xy/xz/yz order, are
**(873.844322413, 543.147811368, 5.324326891,
-309.934714097, 0.336705282, -0.232397899) mm²**.
The signed-mesh physical reference previously measured by the admitted
v6 AnvilCAD fixture is within the V2 bounds, but this is **not**
a substitute for executing the **newly compiled V2 probe**.

Run the command above with
`WITNESS=conformance/external-cad/witness-v6-direct-two-cuts-8mm-moments.txt`
and the genuinely newly built V2 probe; keep the original STEP bytes
and six-stage receipt, update the witness SHA argument, require all
14 rays plus nine independently reconstructed moments, and replay
both actual original geometry and a changed-position (not merely
changed-volume) negative. A candidate is **physically unqualified** until
that exact new executable and both physical cases have been run.
