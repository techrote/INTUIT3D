# SKETCH — transient geometric inference / snapping v1

**Contract:** `@intuit3d/sketch/snapping/v1`, `suggestSketchSnaps(document, cursor, options)`.

- Coordinates, `radiusMm` and `gridMm` are **millimetres in solved sketch coordinates**, not screen pixels. The Workbench converts its cursor/pixel tolerance using its view transform and must rerun on zoom or document edits.
- Point IDs, line IDs, circle IDs are app-owned and stable across dimensional edits. Each returned `id` is **an ephemeral candidate locator**, not an authoritative feature/face identity or authored constraint; `previewOnly: true` on all responses. The `inputSignature` fences edits and save/reopen. To apply any snap, issue explicit constraint/geometry commands through the appropriate owner, re-solve and reject contradictions. Do not persist a snap candidate as an exact geometric reference.
- Supports point, line midpoint and bounded orthogonal segment projection, circle centre and cardinal quadrants, radial circle-perimeter projection and optional nearest rectangular grid point. `excludeIds` prevents self-snapping while dragging. Distances are sorted nearest-first, then fixed inference priority and semantic ID; no implicit constraint precedence changes.
- A consistent `solved` sketch has non-provisional geometry. An `underconstrained` sketch uses current seed-based coordinates; the result is explicitly `provisionalGeometry: true`. Contradictory/numerically failed sources, entity-budget overflow, degenerate lines, nonfinite candidate arithmetic or overflow produce **no** snap candidate; no automatic epsilon enlargement or partial inferred truth.
- `radiusMm` defaults to 2, capped at 1e9; maximum candidates defaults to 16 and is capped at 64; maximum entities defaults/caps at 4096. The routine sorts candidate vectors and re-solves source constraints, so this version is not yet a high-frequency, large-sketch spatial index. It cannot guarantee correct predicates near tangent/sliver conditions, nor does it solve nonlinear constraints.

**Research disposition:** **repair then adopt** pending independent consumer and browser tests. Deterministic Node regressions cover segment clamping/priority, circles, grid, conflicting and underconstrained sketches, numeric overflow, changed dimensions/save/reopen, semantic exclusion, source stamping, budgets, input refusal and 64 cursor/dimension probes. A graphical acceptance gate must verify pointer/world tolerance conversion and real drag behaviour. No PlaneGCS/WASM binary was executed.
