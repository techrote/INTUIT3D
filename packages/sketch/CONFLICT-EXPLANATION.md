# Linear sketch conflict explanation v1

Import `@intuit3d/sketch/conflict-explanation/v1`, call `explainLinearConflict(sketch)`. This is an **additive, derived diagnostic** for the existing axis-separated linear sketch provider. It never edits authored constraints, allocates persistent IDs, authenticates B-rep geometry, or relaxes any tolerances.

When a sketch is inconsistent, the function canonically orders its authored constraint IDs and uses deletion plus a separate irreducibility verification pass. Only `status: 'minimal_conflict'` permits the consumer to highlight `constraintIds`: **one** constraint subset for which the existing solver reports conflict, and for which removing *any one member* resolves that subset. It is an irreducible witness under the current numerical solver, **not** a globally smallest subset, not an enumeration of all conflicts and not proof of an independently exact algebraic unsatisfiable core. Other constraints may also be wrong. Selection remains user-owned; the UI must not delete or automatically repair a member.

On a consistent, redundant or underconstrained source the status is `no_conflict`, retaining `sourceStatus`. When numerical uncertainty is observed, or a witness cannot be independently verified, results are `numerical_failure` or `unverified` with no purported witness. Computational exhaustion returns `budget_exceeded` with no witness and a concrete reason. No geometry is returned. Preserve `inputSignature` as a revision fence; discard results after any authored sketch edit.

Default budgets: at most 64 authored constraints, 192 scalar variables and 192 solver calls. Strict configurable caps: 96 constraints, 256 variables and 256 calls. All subset solves use the existing explicit numerical policy (1e-12 pivot threshold and 1e-9 mm residual ceiling); this function does not alter it. Complexity remains unsuitable for unrestricted live cursor frames; call after a rejected edit or debounce it in the workbench. The API is deterministic under constraint-array permutation for the qualified fixtures, but numeric elimination is not independently proved order/scale invariant.

**Executed regression entry points** (requires Node.js 22+ and repository TypeScript 5.8.3): `node --test packages/sketch/test/conflict-explanation.test.mjs` and `npm run typecheck --workspace @intuit3d/sketch`. Full sketch suite: `npm test --workspace @intuit3d/sketch`. Test positive, contradictory, redundant, underconstrained, multiple conflicts, radius equality, save/reopen, budget exhaustion and near-overflow refusal.
