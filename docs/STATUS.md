- **User-visible CAD experience:** No integrated on-main graphical workbench or direct manipulation is yet demonstrated, despite real model/sketch packages. There is no qualified sketch → exact extrude → cut → modify → save/reopen → independent STEP user workflow.

Real native OCCT 8.0.1 C++, cross-platform isolated deployment, stable provider IPC into the model/workbench and external STEP consumer comparisons remain outstanding.
- **Precision and UX:** Nonlinear constraints, robust sketch predicates, broader operations, screenshot-backed browser/interaction gates, responsive preview scheduling, local secure service/packaging and user acceptance remain unqualified.
